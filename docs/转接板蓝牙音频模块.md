## 概述

转接板通过 USB 挂载 **Qualcomm QCC3084** 类 USB 音频模块，用于蓝牙音箱播放。  
物理按键经转接板 GPIO 采样后，状态反映在 **`status_bit`** 的 bit3～bit5。  
**当前 App 未解析、未使用这些位**；音乐页仅用 `MediaPlayer` + Android 系统音量，与 GPIO 无关。

**首期范围（已确认）：只做音量加减**，对应 **BT_PIO3 / BT_PIO4**（bit4 / bit5）。  
暂停/播放（BT_PIO2 / bit3）暂不实现。

**实施状态（2026-06-10）：仅文档记录，暂不开发。** 当前通过设置页 / 音乐页 / 系统 `STREAM_MUSIC` 调节音量已够用；等需要蓝牙音箱物理键时再按本文接入。

## status_bit 按键位定义

| 位 | 信号 | 含义 | 首期 |
|----|------|------|------|
| bit3 | BT_PIO2 | 暂停/播放 | 不做 |
| bit4 | BT_PIO3 | **音量−** | ✅ 做 |
| bit5 | BT_PIO4 | **音量+** | ✅ 做 |

电平：0=低，1=高。数据来源：串口 0x23 推送或 0x03 读 `0x0001` 实时包 **`values[7]`**。

## 音量键行为（PIO3 / PIO4 · 待联调确认）

转接板把按键变成 **`status_bit` 上的高电平脉冲/保持**，App 侧按电平持续时间区分短按与长按：

| 操作 | 硬件表现（理解） | App 动作 |
|------|------------------|----------|
| **短按** | 输出一段 **高电平脉冲**（宽度 **待实测**） | 音量 **±1 步**（各触发一次） |
| **长按** | 高电平 **持续 ≥ 约 1 秒** | 音量 **持续减 / 持续加**（按住期间重复步进） |

对应关系：

- **PIO3（bit4）** → 音量 **减**
- **PIO4（bit5）** → 音量 **加**

### 待确认项

| 项 | 状态 |
|----|------|
| 短按高电平脉宽（多少 ms） | ❓ **未确认**，需串口抓 `values[7]` 或示波器测 |
| 长按重复步进间隔 | ❓ 建议联调时定（如 200～300 ms/步） |
| 短按是否在 **上升沿** 还是 **下降沿** 计一步 | ❓ 建议以 **上升沿先 +1 步**，长按满 1 s 后再进入 repeat |

### 建议实现逻辑（写代码时用）

```
每收到一帧 status（或轮询间隔 Δt）：
  若 bit4 或 bit5 为 1：
    累计该位高电平持续时间 holdMs
    若刚变为 1（上升沿）→ 立即 ±1 步
    若 holdMs ≥ 1000 ms → 进入 repeat（每 REPEAT_MS ±1 步）
  若变为 0（下降沿）→ 清零 holdMs，退出 repeat
```

联调第一步：在 `HostEnvSerialRepository` 打日志，短按/长按各测几次，记录 **高电平宽度** 和 **0x23 推送周期**，再定 `REPEAT_MS` 和是否需要 debounce。

## 真机声卡快照（2026-06-10 · rk3568_r）

设备：`5ML2546018127423` · `product:rk3568_r`

### ALSA 声卡（`/proc/asound/cards`）

| Card | 名称 | 说明 |
|------|------|------|
| **0** | `rockchipbt` | 板载 BT SCO（`bt-sco-pcm`），playback + capture |
| **1** | `rockchiprk809co` | RK809 编解码器（本机扬声器/麦克风），playback + capture |
| **2** | `rockchiphdmi` | HDMI 音频输出，仅 playback |
| **3** | `QCC3084` | **USB 音频 · 转接板蓝牙模块** · `Qualcomm QCC3084` @ `usb-fd880000.usb-1.3.1` · 仅 playback |

### 节点

- 控制：`/dev/snd/controlC0`～`controlC3`
- USB 蓝牙播放：`/dev/snd/pcmC3D0p`（card3 device0 playback）
- sysfs：`/sys/class/sound/card3` → `id=QCC3084`

### Android 音频路由（`dumpsys audio`）

- 已连接：`type=usb_headset`，name=`USB-Audio - QCC3084`，addr=`card=3;device=0`
- 多数 Stream（`MUSIC`、`SYSTEM`、`NOTIFICATION` 等）当前路由到 **`usb_headset`**
- `STREAM_MUSIC` 当前音量 index=5（usb_headset 侧）
- 系统于 09:30:03 通过 `UsbAlsaDevice` 检测到 USB 音频插入
