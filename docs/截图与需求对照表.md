### image1.png — 主页 · 探头离线

| 项目 | 内容 |
|------|------|
| **需求章节** | 一（总述）、**二-1** 主页样式「探头离线状态」、**二-2** 区域 ①②④⑤⑦⑧ |

| **数据/协议** | 从机无 TCP 数据 → 卡片 `Offline` 态；门状态 ← `status_bit` bit0；主机环境 ← 串口 0xEF |
| **Compose 组件** | `HomeScreen` · `SystemClockHeader` · `HostEnvTicker` · `SlaveProbeCard(state=Offline)` · `DoorStatusChip` · `MessageTicker` · `HorizontalPager` 指示点 |
| **状态** | `ProbeUiState.offline` → 灰阶 Card、`---` 占位 |
