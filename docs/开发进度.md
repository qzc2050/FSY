### ZJB OTA 清单（项 0 展开 · 优先）

> 背景：ZJB 与 RK3568 封在同一平板内，SWD 烧写不便；ZJB 固件侧 OTA **已实现**，缺 App 端推送与联调。

**已有（固件 / 协议）：**
- [x] ZJB App：`ota.c` / `ota.h`（Download 区 + Flag + 状态机）
- [x] ZJB Bootloader：按 Flag 拷贝 Download → App 区
- [x] 协议寄存器：200 开始 / 208 数据包 / 204 状态 / 202 结束+CRC32（地址默认 `0xEF`）
- [x] App 协议编解码：`buildOtaStartFrame` / `buildOtaDataFrame` / `buildOtaDoneFrame` / `buildReadOtaStatusFrame` / `otaCrc32`（`FsyTcpProtocol.kt`）
- [x] 协议表：`程序更新OTA协议_当前实现.csv`

**待做（App 产品化 + 联调）：**
- [ ] OTA 会话管理（选 bin → 写 200 → 分片写 208 → 轮询 204 → 写 202 → 等重启）
- [ ] 走 **主机↔ZJB 串口**（非 TCP）；设备地址 `0xEF`
- [ ] UI 入口（建议：关于本机 / 设置 · 网络旁「转接板固件更新」；进度条 + 失败态）
- [ ] 真机联调：升级成功、CRC 失败可恢复、升级中暂停 0x23 干扰（ZJB 已有 `OTA_IsRealtimeMuted`）
- [ ] 文档：bin 命名/版本约定、失败回退说明

**相关代码：** ZJB `Core/Src/ota.c`、`Bootloader/`、`protocol.c`（REG_OTA_*）；App `net/FsyTcpProtocol.kt`；CSV `程序更新OTA协议_当前实现.csv`。

### LoRa 联调清单（项 4 展开）

- [ ] 内机 + ZJB 各装 E32（信道/地址一致）
- [ ] ZJB `reg123 bit9=1`（电源 + 桥接）；NeiJi `reg123 bit9=1`（协议输出）
- [ ] 上行：NeiJi `0x23` → LoRa → ZJB USART → App，主页出数
- [ ] 下行：App 写寄存器 → ZJB → LoRa → NeiJi，读回一致
- [ ] 与网口并存：`ProbeLinkRouter` 按最后 0x23 来源选 SERIAL / TCP

**相关代码：** NeiJi `Hardware/lora/`、`fsy_link.c`；ZJB `protocol.c` / `config_flash.c` / `lora_boot.c`；App `ProbeLinkRouter` + 串口路径；协议备注 `辐射报警仪_reg122_reg123_reg15_协议备注.txt`。

## 探头主线使用流程

1. 主页右滑打开侧栏 → **设置** → **探头管理**
2. **+ 添加探头** → 组播列表选设备 → **添加**（自动保存本机，短暂显示「保存成功」）
3. 连上 TCP 后自动读寄存器刷新表单；可改名称/位置/阈值/声光等（写从机规则见阶段小结）
4. 仅改名称/位置/列表时点底部 **保存**；删除需确认，立即从本机与主页移除
5. 返回主页：已保存探头 TCP 连接，收到 **0x23** 后卡片显示实时数据
6. Logcat 过滤：`NetShield` 或 `package:com.raydose.netshield`
