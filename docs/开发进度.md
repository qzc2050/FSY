**LoRa OTA — 暂不实施（2026-07-21 结论）**

- [x] 链路审查：App → 串口 → ZJB → LoRa → NeiJi；mute 停 Poll 已修，但**不作为产品 OTA 通道**
- [~] 实机试传：**极慢**（595KB 固件约 4600 包 @ 19.2k 空中速率，理论仅空中就数分钟级）
- [~] 传数分钟后 **App 超时**；当前 DATA **不重试、无 reg204 续传**，单包丢失即整次失败
- [ ] **暂不实施** LoRa 完整固件 OTA；正式升级走 **网口 / CAN**（及 ZJB 串口 OTA）
- [ ] 若将来要做 LoRa OTA，需单独设计：断点续传、包序号/偏移、更长超时与重试、可选差分/压缩（非当前 128B×4600 包方案）

## 探头主线使用流程

1. 主页右滑打开侧栏 → **设置** → **探头管理**
2. **+ 添加探头** → 组播列表选设备 → **添加**（自动保存本机，短暂显示「保存成功」）
3. 连上 TCP 后自动读寄存器刷新表单；可改名称/位置/阈值/声光等（写从机规则见阶段小结）
4. 仅改名称/位置/列表时点底部 **保存**；删除需确认，立即从本机与主页移除
5. 返回主页：已保存探头 TCP 连接，收到 **0x23** 后卡片显示实时数据
6. Logcat 过滤：`NetShield` 或 `package:com.raydose.netshield`
