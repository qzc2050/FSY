# NeiJi 开发计划

> 工程：`probe/Neiji/NeiJi/`  
> 旧代码参考：`probe/FSY-I/RAD-I/`（不迁移，只读）

## 阶段划分

| 阶段 | 目标 | 状态 |
|------|------|------|
| **0** | CubeMX 空工程 + FreeRTOS + 串口日志 | ✅ |
| **1** | 协议层：帧解析/组包、寄存器表、串口回环测试 | 🔴 |
| **2** | W5500 以太网 + TCP 服务 + 组播发现 | 🔴 |
| **3** | 盖革 TIM 计数 + 剂量率 + 0x23 实时上报 | 🔴 |
| **4** | QSPI Flash 5 分钟历史 + 0x006C 回补 | 🔴 |
| **5** | 环境传感器（I2C）+ 寄存器 3~11 | 🔴 |
| **6** | LVGL 本地 UI | 🔴 |
| **7** | OTA（对接 IAP Bootloader） | 🔴 |

## 阶段 1 交付物

- `Protocol/frame/` — CRC16、RTU 帧解析
- `Protocol/register/` — 与 0502.csv 对齐的寄存器定义
- `Protocol/transport/uart_transport.c` — USART3 或指定调试口
- Python/串口工具可读写寄存器

## CubeMX 下一步

在 `NeiJi.ioc` 中按硬件原理图添加外设，生成代码后**不要**把业务逻辑写进 `Core/User/` 的 USER CODE 大块，应放到 `App/`、`Hardware/`。

优先添加：**SPI1（W5500）**、**TIM（盖革）**、**QUADSPI（Flash）**、**I2C（传感器）**。
