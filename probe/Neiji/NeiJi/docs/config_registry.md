# NeiJi 配置项梳理（对照《辐射报警仪协议命令和寄存器表10》+ FSY-I 实现）

> 目的：工厂工具 / App / 串口 后期可读写；片内 **Set 区 Flash** 持久化。  
> 寄存器地址为协议 **十进制地址**（与 FSY-I `net_raw_app.h` 一致）；32 位项占 **2 个连续寄存器地址**。

---

## 一、分类说明

| 类别 | 含义 | 掉电保存 |
|------|------|----------|
| **A. 协议标准** | xlsx / `net_raw_app.h` 已定义 | 按项 |
| **B. 扩展镜像** | FSY-I 内部寄存器镜像（0–17），与 0x23 实时区部分重叠，NeiJi **不建议照搬** | 按需 |
| **C. 协议待扩展** | 现仅代码写死或串口命令（EWMA 等），**需在协议中新增寄存器** | 建议 Flash |
| **D. 只读/运行时** | 传感器、OTA 状态等 | 否 |

**NeiJi 当前实现**：仅 0x23 实时区（reg 1–21）+ 0x03 读；**无写寄存器、无 Flash 配置**。

## 二、A 类 — 协议标准配置（已有寄存器地址）

| 54 | 温度上阈值 | uint32 | ℃ ×10 | ✅ |
| 56 | 温度下阈值 | uint32 | ℃ ×10 | ✅ |

| 60 | 气压下阈值 | uint32 | 同上 | ✅ |
| 62 | 湿度上阈值 | uint32 | % ×10 | ✅ |
| 64 | 湿度下阈值 | uint32 | % ×10 | ✅ |
| 66 | CO2 上阈值 | uint32 | ppm ×100 | ✅ |

| 70 | PM2.5 上阈值 | uint32 | μg/m³ ×100 | ✅ |

### 2.2 报警与控制 reg 82–123

| 起始地址 | 名称 | 类型 | 说明 | Flash |
|----------|------|------|------|-------|

| 86 | **序列号** | 16B ASCII | 8 寄存器；有效通常 12 字符 | ✅ |

| 123 | **控制位 2** | uint16 | bit0 声 / bit1 光 / bit2 显示 等 | ✅ |

## 三、B 类 — 型号 / IP / 协议类型（需统一 NeiJi 方案）

FSY-I 在 **保持寄存器 0–17** 写了 SN 短码、IP、型号、协议字符串，但与 **0x23 实时区 reg 9/11/13 等地址重叠**，NeiJi 建议 **不用 0–17 镜像**，改为独立扩展区 + Flash。

| 数据 | FSY-I 做法 | NeiJi 建议 |
|------|------------|------------|
| **产品型号** | 宏 + reg 8–13 镜像 | **协议扩展 reg 130–135**（12B ASCII）+ Flash |
| **IP 地址** | reg 6–7 读 W5500 当前 IP（DHCP 结果） | **只读 reg 6–7** 镜像当前 IP；**静态 IP 见 C 类** |
| **协议类型字符串** | reg 14–17 镜像 | 可选 **reg 136–139**（8B）或仅 UDP 用数字 `protocol_type=2` |
| **UDP 发现用 SN/型号** | 来自 `sys_cfg` / 宏 | 与 reg 86 / reg 130 同步 |

## 四、C 类 — 协议待扩展（你提到的 EWMA、灵敏度等）

现位于 `dose_rate.c` / FSY-I **串口命令**，**未进 xlsx**。建议在 **reg 124–199 空档** 新增（与 OTA 200+ 隔开）：

### 4.1 盖革 / 剂量率算法（建议 reg 140–151）

| 建议地址 | 名称 | 类型 | 默认值 | 说明 |
|----------|------|------|--------|------|
| 140 | **灵敏度** | uint32 | 120 | cpm  per uSv/h ×100 或 IEEE754 两寄存器（实现时定一种） |
| 142 | EWMA **threshold_cps** | uint16 | 100 | CPS 高阈值，以上用 fast α |
| 143 | EWMA **threshold_delta** | uint16 | 10 | 相邻 CPS 差，触发 boost |
| 144 | EWMA **alpha_low** | uint32 | 0.03 | ×10000 存整数（300）避免浮点协议 |
| 146 | EWMA **alpha_high** | uint32 | 0.35 | ×10000 → 3500 |
| 148 | EWMA **boost_duration** | uint16 | 20 | 秒 |
| 149 | 剂量率 **量程上限** | uint32 | 10000 | uSv/h，对应 `GEIGER_RATE_LIMIT` |
| 151 | 配置 **提交/恢复** | uint16 | — | 写 `0x0001` 提交 Flash；`0x0002` 恢复出厂（可选） |

> 写 140–148 可先改 RAM，**151 提交** 或 **整段写完后自动 Commit**（与 FSY-I reg94 时间「写满 4 字再生效」类似）。

### 4.2 网络静态配置（建议 reg 152–165，DHCP 时部分只读）

| 建议地址 | 名称 | 类型 | 说明 |
|----------|------|------|------|
| 152 | **DHCP 使能** | uint16 | 0=静态 IP，1=DHCP（对应 `USE_DHCP`） |
| 153 | 保留 | | |
| 154 | **静态 IP** | 4B | 2 寄存器，同 FSY-I reg6–7 编码 |
| 156 | **子网掩码** | 4B | 2 寄存器 |
| 158 | **网关** | 4B | 2 寄存器 |
| 160 | **DNS** | 4B | 2 寄存器 |
| 162 | **MAC** 只读 | 6B | 3 寄存器，工厂查看 |
| 165 | 网络 **应用** | uint16 | 写 1 重启 W5500 网络栈（改 IP/DHCP 后） |

当前 NeiJi：**仅 DHCP**；静态 IP 寄存器可先定义，后期实现。

### 4.3 其它 FSY-I Flash 有、协议无或未实现

| 参数 | FSY-I `sys_cfg` / Flash | 协议建议 |
|------|-------------------------|----------|
| 硬件版本 HW | `hw_version[16]` | 扩展 **reg 166–173**（16B ASCII） |
| 语言 | `language` 0/1 | 扩展 **reg 174** |
| 屏幕亮度 | `bright_sz` | 扩展 **reg 175**（NeiJi 无屏可预留） |
| 剂量阈值 shadow | `dose_th_shadow_flags` | 内部状态，可不暴露协议 |
| 0x23 **上传周期** | `NET_ACTIVE_UPLOAD_PERIOD_MS` | 扩展 **reg 176** ms（可选） |

## 六、Flash（Set 区）建议存储字段

与 `DeviceCfgBlob` 对齐，**上电 Load → RAM → 同步到协议寄存器**；写协议 **Commit → Set 扇区**。

| 字段 | 对应协议 |
|------|----------|
| magic / version / crc32 | — |
| model[12] | reg 130–135 |
| sn[16] | reg 86–93 |
| dev_addr | reg 121 |
| alarm_biten | reg 82 |
| th_* 全部阈值 | reg 50–72 |
| alarm_volume, ctrl2, alarm_sound/light | reg 122–123 等 |
| sensitivity | reg 140 |
| ewma_* 五项 | reg 142–148 |
| dhcp_enable, static ip/mask/gw/dns | reg 152–160 |
| hw_version | reg 166+ |
| language, bright | reg 174–175 |

**不写 Flash**：RTC 时间（94）、重启（120）、OTA、实时传感器。

## 七、NeiJi 实现优先级建议

| 阶段 | 内容 |
|------|------|
| **P0 工厂** | reg 86 SN、121 地址、130 型号、94 时间、98 版本只读 |
| **P1 报警** | reg 50–72 阈值、82 报警使能、122–123 |
| **P2 算法** | reg 140–148 灵敏度 + EWMA；151 提交 |
| **P3 网络** | reg 152+ 静态 IP / DHCP 切换 |
| **P4** | 108–112 历史、200+ OTA |

## 八、协议功能码（读写方式）

| 操作 | 功能码 | 适用 |
|------|--------|------|
| 读多个 | 0x03 → 0x13 | 序列号、阈值、EWMA 等 |
| 读单个 | 0x05 → 0x15 | 地址、DHCP 开关 |
| 写单个 | 0x06 → 0x16 | reg 121 地址 |
| 写多个 | 0x10 → 0x20 | SN、时间、阈值块、EWMA 块 |
