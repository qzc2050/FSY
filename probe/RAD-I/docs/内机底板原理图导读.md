## 1. 总览（第 1 页 BLOCK）

```
24V 电源
    ↓
STM32H743IIT6 ─┬─ W5500 + RJ45（有线以太网，SPI）
               ├─ HLK-7688A（WiFi 模组，同 RJ45 区域）
               ├─ TJA1051（CAN）
               ├─ E32-433T20S（433MHz LoRa，UART5）
               ├─ LTDC + FPC 屏
               ├─ BME280 / AHT20 / ENS160 / PM2.5
               ├─ 盖革高压 COUNT + HV_EN
               ├─ W25Q64（QSPI 8MB）+ W9825G6KH（SDRAM 32MB）
               ├─ PCF85063（RTC，I2C）
               ├─ Type-C USB + CH340X（调试串口）
               └─ WS2812B 状态灯
```

## 3. 电源架构（第 2 页 POWER）

```
VCC_24V（DC 插座 DC-044）
    │
    ├─ F1 保险丝、TVS、共模电感 L1
    │
    ▼
U1 TPS5430 ──→ SYS_5V（约 5V 系统母线）
    │
    ├─ U35 TPS2117：SYS_5V 与 VBUS 二选一供电
    │
    ▼
U3 TPS562201 ──→ VCC_3V3（MCU / W5500 / 大部分数字电路）
    │
    └─ VCC_5V：部分外设（LoRa、LCD、USB 相关）
```

要点：

- 整机**进线 24V**，板上自己降到 3.3V / 5V。
- Type-C **VBUS** 可通过 TPS2117 参与供电切换（便携/调试场景）。
- 盖革高压、部分模拟在 5V 或独立高压模块上。

## 5. 以太网（第 4 页 ETHERNET）— 重点

板上有**两路网络相关硬件**：

### 5.1 W5500（当前固件主用）

| 项目 | 说明 |
|------|------|
| 芯片 | W5500（硬件 TCP/IP） |
| 接口 | **SPI** → MCU（网络名 WLAN_MOSI/MISO/SCLK/CS） |
| PHY | 芯片内置，外接 RJ45 变压器 HR915210C |
| 复位 | RSTn，网络名 WLAN_RST / PHY_RST |
| 中断 | INTn，网络名 WLAN_INT |
| 时钟 | 25MHz 晶振 Y2 |
| 电源 | PHY_3V3 / WLAN_3V3 |

**与固件关系**：`device.c` / `w5500_dhcp.c` / `socket.c` 全部走这颗芯片；DHCP、TCP 5001、UDP 2468 组播均经 W5500。

### 5.2 HLK-7688A（WiFi 模组，原理图有、固件未作主通道）

| 项目 | 说明 |
|------|------|
| 模组 | HLK-7688A（联发科方案类 WiFi） |
| 接口 | SPI、UART、I2S 等多脚；与 RJ45 网口同页布局 |
| 使能 | HLK_EN |
| 复位 | WDT_RST_N / PHY_RST 相关电路 |

框图里写了 **HLK_7688A + RJ45**，说明硬件预留 **有线+WiFi** 双方案；当前 RAD-I 代码以 **W5500 有线** 为主，HLK 是否启用需另查是否有独立固件分支或未移植驱动。

## 7. 传感器 / 盖革（第 6 页 SENSORS）

```
HV_EN ──→ 高压使能（Q7 等开关电路）
COUNT ──→ 盖革脉冲计数输入 MCU（geiger 定时器）
U24     ──→ 高压产生模块（5V/3.3V 控制，HV 输出）
```

- 盖革管需要 **高压（HV）** + **脉冲计数（COUNT）** 两路配合。
- 固件 `Geiger_Task` 负责计数；`HV_EN` 控制高压上电。
- 剂量率算法在 `DOSE_RATE/`（EWMA）。

## 8. 硬件 ↔ 软件快速对照

| 你想确认… | 看原理图页 | 看固件 |
|-----------|------------|--------|
| 网线为什么能 DHCP | 第 4 页 W5500+RJ45 | `w5500_dhcp.c` |
| 串口发命令没反应 | 第 5 页 CH340+UART1 | `cmd.c`, `Uart_Recv_Task` |
| 探头怎么被 Android 发现 | 第 4 页以太网 | UDP 2468，`Broadcast_Fill_Data` |

## 9. 与原理图相关的维护注意

1. **MCU 型号**：原理图 **H743**，工程若按 **H750** 配时钟/Flash 分区，以 Keil 实际选型为准。
2. **RTC 芯片名**：图上是 **PCF85063**，代码文件名 **pcf8563**，属 NXP PCF85xx 系列，驱动接口一致即可。
3. **双网口方案**：W5500（已用）+ HLK-7688A（硬件在，固件未必启用）；排查网络问题先查 W5500 链路和 SPI。
4. **默认 MAC**：固件写死 `CC:08:DC:11:11:11`（`device.c`），多台内机同网需改 MAC 或 DHCP 冲突。
5. **24V 供电**：无 24V 或 5V/3.3V 电源异常时，表现为整机不启动或以太网 PHY 不上电。
6. **PM2.5 插座**：GH1.25-8P 可拔插，接触不良会导致 PM2.5 数据为 0。
