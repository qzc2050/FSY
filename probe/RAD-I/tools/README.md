## 概述

本测试工具用于测试辐射报警仪协议（net_raw_protocol），支持以下功能：

- 扫描并连接串口
- 发送所有协议定义的指令
- 接收并解析返回数据
- 实时显示串口数据
- 保存测试数据

## 使用方法

### 方法一：GUI 上位机（推荐）

#### 启动 GUI 工具

```bash
cd tools
python net_raw_tester.py
```

#### 界面说明

1. **串口连接区域**
   - 选择串口号
   - 选择波特率（默认 115200，最高支持 921600）
   - 点击"连接"按钮

2. **协议指令区域**
   - 设置设备地址（默认 1）
   - 选择功能码
   - 设置寄存器地址和值

3. **快捷指令区域**
   - 一键发送常用指令
   - 读辐射量、温度、气压等
   - 重启设备

4. **自定义指令区域**
   - 发送原始 HEX 数据

5. **接收数据显示**
   - 实时显示接收数据
   - 自动解析协议帧
   - 支持保存数据

### 方法二：命令行工具

#### 启动命令行工具

```bash
cd tools
python net_raw_tester_cli.py -p COM3 -b 115200 -a 1
```

#### 参数说明

- `-p, --port`: 串口号（如 COM3 或 /dev/ttyUSB0）
- `-b, --baud`: 波特率（默认 115200，最高支持 921600）
- `-a, --addr`: 设备地址（默认 1）
- `-l, --list`: 列出可用串口
- `-h, --help`: 显示帮助信息

#### 示例

```bash
# 列出所有可用串口
python net_raw_tester_cli.py -l

# 连接 COM3，波特率 115200，设备地址 1
python net_raw_tester_cli.py -p COM3 -b 115200 -a 1

# 连接 COM3，波特率 921600，设备地址 5
python net_raw_tester_cli.py -p COM3 -b 921600 -a 5

# 连接 /dev/ttyUSB0，设备地址 5
python net_raw_tester_cli.py -p /dev/ttyUSB0 -a 5
```

## 协议指令说明

### 功能码

| 功能码 | 名称 | 说明 |
|--------|------|------|
| 0x03 | 读多寄存器 | 读取多个连续寄存器 |
| 0x05 | 读单寄存器 | 读取单个寄存器 |
| 0x06 | 写单寄存器 | 写入单个寄存器 |
| 0x10 | 写多寄存器 | 写入多个连续寄存器 |
| 0x13 | 读多应答 | 读多寄存器响应 |
| 0x15 | 读单应答 | 读单寄存器响应 |
| 0x23 | 主动上传 (多) | 设备主动上传多寄存器数据 |
| 0x25 | 主动上传 (单) | 设备主动上传单寄存器数据 |

### 常用寄存器地址

| 地址 | 名称 | 说明 | 量纲 |
|------|------|------|------|
| 1 | DOSE_RATE | 辐射量 | *100 uSv/h |
| 3 | TEMP | 温度 | *10 ℃ |
| 5 | PRESS | 气压 | Pa |
| 7 | HUM | 湿度 | % |
| 9 | CO2 | CO2 浓度 | ppm |
| 11 | PM25 | PM2.5 | *10 μg/m³ |
| 13 | ALARM_BIT | 报警状态 | 位图 |
| 50 | THR_DOSE_HI | 辐射量高阈值 | - |
| 120 | REBOOT | 重启控制 | 写 1 重启 |

## 示例

### 示例 1：读取辐射量

**GUI 方式:**
1. 连接串口
2. 点击"读辐射量"按钮
3. 查看返回数据

**命令行方式:**
```bash
python net_raw_tester_cli.py -p COM3
# 选择 1
```

**发送指令:**
```
01 05 01 00 01 00 D5 CA
```

**预期响应:**
```
01 15 01 00 XX XX CRC_LOW CRC_HIGH
```

**数据解读:**
- 寄存器值 = XX XX (小端序)
- 辐射量 = 寄存器值 / 100.0 (uSv/h)

### 示例 2：读取温度

**发送指令:**
```
01 05 03 00 01 00 D4 2A
```

**预期响应:**
```
01 15 03 00 XX XX CRC_LOW CRC_HIGH
```

**数据解读:**
- 寄存器值 = XX XX (小端序)
- 温度 = 寄存器值 / 10.0 (℃)

### 示例 3：写寄存器（重启设备）

**发送指令:**
```
01 06 78 00 01 00 49 3B
```

**预期响应:**
```
01 16 78 00 01 00 CRC_LOW CRC_HIGH
```

### 示例 4：使用串口指令协议

**通过串口调试工具发送:**
```
AA 02 01 05 01 00 00 00 55
```

**说明:**
- `AA`: 前缀
- `02`: SEND_REG 命令
- `01`: 设备地址
- `05`: 功能码（读单寄存器）
- `01 00`: 寄存器地址 1（小端序）
- `00 00`: 寄存器值 0
- `55`: 结束符

## 故障排查

### 问题 1：找不到串口

**解决方法:**
1. 检查串口线是否连接正确
2. 确认已安装串口驱动（如 CH340、CP2102 等）
3. 使用 `-l` 参数查看可用串口列表
4. 在设备管理器中查看串口号

### 问题 2：连接失败

**解决方法:**
1. 确认串口未被其他程序占用
2. 检查波特率设置是否正确
3. 尝试重新插拔串口线
4. 重启设备

### 问题 3：无响应

**解决方法:**
1. 检查设备地址是否正确
2. 确认 CRC 计算是否正确
3. 增加超时时间
4. 检查设备是否正常工作

### 问题 4：CRC 校验失败

**解决方法:**
1. 确认 CRC 算法是否正确（CRC16 MODBUS）
2. 检查字节序（小端序）
3. 验证数据完整性

## CRC16 参考实现

```python
def calculate_crc16(data: bytes) -> int:
    crc = 0xFFFF
    for byte in data:
        crc ^= byte
        for _ in range(8):
            if crc & 0x0001:
                crc = (crc >> 1) ^ 0xA001
            else:
                crc >>= 1
    return crc
```
